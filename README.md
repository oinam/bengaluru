# Bengaluru isometric map

A zoomable, searchable isometric pixel-art map of Bengaluru, drawn by code from open
data: OpenStreetMap, Google Open Buildings, and ESA WorldCover. No photographs, satellite
imagery, or image models go into the picture.

Planned, not started. The plan is in [docs/PLAN.md](docs/PLAN.md).

It follows the [Manipur map](https://manipur.oinam.com) and reuses its pipeline.

## Inspiration

- [Isometric Imphal](https://manipur.oinam.com), the first map in this family
- [Pixel Chennai](https://pixelchennai.com/)
- [Isometric Mumbai](https://isometricmumbai.com/)
- [Isometric Cities](https://isometriccities.com), the directory, and its
  [guide](https://isometriccities.com/guide/how-to-make-an-isometric-city-map/)
