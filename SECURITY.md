# Security

This is a static map: a viewer, tiles, and the code that draws them. It has no accounts,
no cookies, and no forms, and it stores nothing about its visitors.

If you find a security problem in the code, the build, or the site, tell Brajeshwar
privately through [brajeshwar.com](https://brajeshwar.com) and leave it out of public
issues until it is fixed. Say what you found and how to see it.

A mistake in the map itself, a wrong name or a missing building, is not a security
problem: use "Suggest a correction" on the map, or open an issue.
